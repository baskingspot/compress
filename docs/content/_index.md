Compression codecs in pure Zig: Snappy, DEFLATE, gzip, zlib, and Zstandard, plus a Brotli decoder.

The guide for this site is being written. Until it lands, each codec's README documents its API, error sets, and buffer sizes, and the [repository README](https://github.com/baskingspot/compress#readme) lists what is and isn't implemented.
